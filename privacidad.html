Política de privacidad

Ni Idea Subidas · última actualización: 6 de noviembre de 2026

«Ni Idea Subidas» es una aplicación de uso personal del creador del canal de YouTube «Ni Idea Tenías Esto». Usa los YouTube API Services. Al usarla aceptas las Condiciones del servicio de YouTube y se aplica la Política de privacidad de Google.

Qué datos se usan

  • Un token de acceso OAuth del canal propietario, para subir vídeos a ese canal.
  • Datos públicos de los vídeos subidos (identificador, estado y estadísticas: vistas, «me gusta», comentarios).

No se recogen datos de otros usuarios ni de los espectadores.

Cómo se guardan y comparten

Los datos se guardan solo en el servidor privado del propietario. No se venden, no se comparten con terceros y no se usan para publicidad. Las estadísticas se conservan mientras el vídeo exista; el token se elimina al revocar el acceso.

Cómo revocar el acceso

Puedes retirar el permiso en cualquier momento desde la configuración de seguridad de tu cuenta de Google.
